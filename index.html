📖 工具配置说明

照着下面的步骤操作，几分钟就能配好一个工具。内容较多可上下滚动。

一、你在这里配的到底是什么

工具界面上的每个输入框，最终都会被转换成 RunningHub 的 nodeInfoList 参数发给接口：

{ "nodeId": "节点ID", "fieldName": "字段名", "fieldValue": "填进去的值" }

所以在配置窗口里，一行「输入项」= nodeInfoList 里的一个元素。图片类的值会由工具先上传、再自动替换成返回的文件名，你不用手填。

二、开始前准备

  • 顶栏 🔑 已填好 API Key；
  • 本工具可调用平台上已经发布并开放 API 的工作流和应用；调用费用从你自己的钱包 / RH 币中扣除。
  • 在该应用 / 工作流的「API 调用」页面能看到请求示例（下一步要用）。

三、基础信息怎么填

字段说明
图标 / 工具名称只影响左侧列表的显示，随便起。
标签决定左侧分组，可加多个（下拉选已有标签或输入新标签），同一个工具会出现在多个分组里；留空则进「未分类」。
实例类型default(24G) / plus(48G) / ultra(84G)。显存不够（报 OOM）时换更大的。
类型AI 应用 或 ComfyUI 工作流。选错会报 webapp not exists。
IDAI 应用填 webappId；工作流填 workflowId。

webappId 在哪：RunningHub 里打开该应用，浏览器地址栏 /app/ 后面那串数字；或点「API 调用」看示例地址中的 ai-app/{数字}。平台上已发布的应用同理，ID 一样能取到（未开放 API 调用时会报无权限 / 应用不存在）。

workflowId 在哪：打开工作流 →「API 调用」→ 示例请求地址中的 workflow/{数字}。

四、节点ID 和 字段名怎么找（最关键的一步）

在应用的「API 调用」页面，官方会给出类似下面的示例请求体。把其中 nodeInfoList 的每一项，在配置窗口里加一行：

{
  "webappId": "2119272366319685634",
  "apiKey": "你的Key",
  "nodeInfoList": [
    { "nodeId": "1",  "fieldName": "image", "fieldValue": "api/xxxx.png" },
    { "nodeId": "25", "fieldName": "text",  "fieldValue": "黄昏效果，真实建筑" },
    { "nodeId": "30", "fieldName": "value", "fieldValue": "2048" }
  ]
}

对照关系：节点ID = nodeId，字段名 = fieldName，默认值 = fieldValue 的示例值（可留空），显示名称是你自己起的中文名（只影响界面）。

如果示例里没有 nodeInfoList，或它是空的：说明这个应用没暴露输入参数，直接保存、不用加输入项，点「开始生成」即可；也可以到工作流画布里点开节点，在右侧面板查看参数名（一般是 text / image / seed / value）。

五、输入项类型怎么选

界面类型常见 fieldName说明
图片上传image先上传再自动填入返回的 fileName，适用于 LoadImage 节点。
多行文本text提示词、反推提示词等长文本。
单行文本text / string短文本。
数字value / seed / steps / cfg分辨率、步数、强度、种子等。
下拉选择value默认值里写全部候选，用英文逗号分隔，如 true,false 或 1024,1536,2048。

特殊情况：

  • 种子：fieldName 一般是 seed；默认值填 -1 表示每次随机，填固定数字可复现同一张图。
  • 布尔开关：fieldName 通常是 value，值只能是 true 或 false，建议用「下拉选择」类型。
  • 分辨率：多数节点把尺寸放在一个 number 节点上，fieldName 是 value，单位是像素。

  • 工具立刻出现在左侧列表，可拖动排序、可改标签；
  • 已授权「配置目录」时，会同时写入 tools/工具名.rhtool.json，下次启动自动读取；

八、常见报错对照

提示原因与解决
webapp not exists类型或 ID 填错。工作流 ID 却选了「AI 应用」最常见，检查「类型 + ID」是否匹配。
Node info error / 节点信息异常节点ID 或 字段名 与工作流对不上。按「API 调用」示例逐个照抄；该工作流不接受空参数时，必须至少配一条输入项。
没有可提交的参数所有输入项都没填值。填上值，或删掉用不到的输入项。
Your balance is insufficient钱包余额不足，去 RunningHub 充值或更换有余额的 Key。
任务失败 / 一直排队应用被下架、实例繁忙或显存不足；稍后重试，或把实例类型调大。

九、新手建议

  • 先只配「1 个图片 + 1 个提示词」跑通，再逐步加参数，出问题好排查；
  • 对比效果时用固定种子（如 12345），只改一个参数；
  • 长文本不好编辑时，直接点输入框，会弹出大窗口编辑；
  • 跑错了立刻点「⏹ 立即取消」，避免继续产生费用。
