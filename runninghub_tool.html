RunningHub 图生图工具

上传图片 + 输入提示词 → 调用 RunningHub 工作流 API 生成图片
⚙️ API 配置（填一次，自动保存）

💡 怎么找节点 ID：在 RunningHub 网页打开你的工作流，每个节点右上角的数字就是 nodeId。 图片填到 LoadImage 节点（字段 image），提示词填到 CLIPTextEncode 节点（字段 text）。 也可点工作流页面「导出工作流 API」下载 JSON 后搜索 LoadImage / CLIPTextEncode 确认。

1️⃣ 上传原图
点击选择图片，或拖拽图片到这里
支持 JPG / PNG / WEBP，最大 30MB
2️⃣ 输入提示词并运行
3️⃣ 生成结果
生成的图片会显示在这里
