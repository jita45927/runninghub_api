# Checklist

## P0 · 更新链与本地服务边界

- [x] 更新清单缺少 `sha256` 或 `size` 时，下载流程拒绝进入 `ready`
- [x] 安装包摘要/大小不匹配时，`/update/install` 拒绝执行并提示重新下载
- [x] 更新清单缺少 `signature` 时，客户端按无更新处理，不进入下载流程
- [x] 清单版本、SHA256、大小或下载地址被篡改后，Ed25519 验签失败并拒绝该源
- [x] 签名私钥位于 `.private/` 且被 `.gitignore` 忽略；公钥已内置客户端
- [x] `python 发布更新.py --publish` 在缺少私钥时拒绝发布；`--generate-only` 有私钥时自动签名
- [x] 清单版本不高于当前版本时，安装流程拒绝执行
- [x] 安装包下载地址不再接受与项目无关的宽泛白名单主机
- [x] 超大 JSON 请求体返回 413，且服务端未读入完整请求体
- [x] 负数或非数字 `Content-Length` 返回 400，不出现线程挂起
- [x] 封面上传超过上限被拒绝，正常图片仍可保存
- [x] 更新/公告清单超过上限被拒绝，正常清单仍可解析
- [x] 结果下载超过上限时中止并删除临时文件
- [x] 第三方页面 iframe 加载本地界面被浏览器拒绝
- [x] 响应包含 `X-Content-Type-Options`、`Referrer-Policy`、`X-Frame-Options` / `frame-ancestors`
- [x] 请求 `/server.py`、`/appinfo.txt`、`/user_tools/`、`/启动日志.log`、`/.git/` 均返回 404
- [x] `/`、`/css/`、`/js/`、`/ICO/`、`/appinfo`、`/tools/`、`/downloads/`、`/update/*` 功能正常
- [x] 页面不再出现目录列表

## P1 · 数据一致性与运行可靠性

- [x] `/save-tool` 收到数组/`null`/缺字段时返回 400，不写入文件、不抛未捕获异常
- [x] 保存同 `webappId`、不同名称的两个工具后，两份配置均存在
- [x] 仅修改工具名大小写后保存，配置文件存在且内容为新名称
- [x] 保存 `content` 非法时，磁盘不出现半截或损坏配置
- [x] `/save-tool` 返回 500 或断网时，界面不显示“已保存”
- [x] 删除工具写盘失败时，界面不显示“已删除”
- [x] 连续两次请求 `/update/download`，第二次返回 409，只有一个 `.part` 写入者
- [x] 客户端传入非法 `manifest` 时返回 400，不出现 500
- [x] 任务创建后刷新页面，可恢复查询/取消，且不重复提交任务
- [x] 无法恢复任务时，界面明确提示状态丢失
